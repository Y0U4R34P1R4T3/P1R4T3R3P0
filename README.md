# 🏴‍☠️ P1R4T3R3P0

> **Repositorio CLI para Linux — Juegos, Películas y Series**

¡Bienvenido a bordo, marinero! **P1R4T3R3P0** es un gestor de descargas automatizado para la terminal de Linux. Te permite buscar, instalar y mantener actualizados tus juegos y multimedia en un solo paso.

---

### ⚡ Instalación Rápida

Ejecutá cualquiera de estos dos comandos en tu terminal para instalar **Pirate CLI**:

> ⚠️ **Nota importante:** El repositorio se actualiza constantemente. Se recomienda ejecutar siempre `pirate update` antes de descargar contenido para contar con las últimas versiones y mirrors activos.

---

### 📜 Uso y Comandos

Una vez instalado, podés ejecutar el comando `pirate` directamente en tu terminal:

| Comando | Descripción |
| :--- | :--- |
| `pirate update` | Actualiza el catálogo y el script a la última versión disponible |
| `pirate search <nombre>` | Busca contenido dentro del catálogo por palabra clave |
| `pirate listall` | Muestra todo el catálogo disponible |
| `pirate listgames` | Filtra y muestra solo el catálogo de juegos |
| `pirate listmovies` | Filtra y muestra solo las películas |
| `pirate listseries` | Filtra y muestra solo las series |
| `pirate install <id>` | Descarga, descomprime e instala un elemento |
| `pirate upgrade` | Actualiza todos tus juegos instalados a la versión más reciente |
| `pirate request "<nombre>"` | Abre una petición en GitHub para solicitar nuevo contenido |
