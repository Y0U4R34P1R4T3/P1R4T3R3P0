# P1R4T3R3P0
Repositorio de Linux


Este repositorio esta en cambio constante, así que recomiendo estar usando antes de cualquier descarga el comando 'pirate update' para evitar errores de versiones de los archivos.

Para descargar este repositorio puedes usar cualquiera de estos dos comandos:
WGET { wget -qO- https://raw.githubusercontent.com/Y0U4R34P1R4T3/P1R4T3R3P0/main/install.sh | sh }
CURL { curl -sSL https://raw.githubusercontent.com/Y0U4R34P1R4T3/P1R4T3R3P0/main/install.sh | sh }

Ante cualquier duda o problema, puedes escribirla en el apartado de Issues.
